---

### 🤖 What I build

- **AI operations agent:** a Claude Code agent that takes natural-language tasks and runs them end to end. It reaches servers, collects reports, closes tickets with logged hours and notifies the team in Google Chat.
- **Autonomous scheduled checks:** AI agents triggered by systemd timers run recurring checks (e.g. client server disk usage) and send standardized alerts by severity (*nothing to do / watch / act today*), each one with a recommended action.
- **AI skills on top of the Semaphore API:** they provision a new client (server, user, database, apps, nginx), enroll terminals in WireGuard and grant SSH keys, all from a single natural-language request.
- **Modular infrastructure as code:** Ansible roles, Jinja2 templates and per-product variables, run through Semaphore UI so the team can deploy without knowing every command.
- **Rootless containers in production:** Django, Angular, legacy systems and an NF-e issuer, running with named volumes and SELinux, without root.
- **Data:** PostgreSQL upgrades from 9.2 to 18 in containers, plus a read-only replica via log shipping (pgBackRest + S3).
- **Cloud and security:** AWS IAM Identity Center (SSO + MFA), Secrets Manager across accounts, admin access via SSM and WireGuard with no SSH exposed to the internet, and Cloudflare Tunnel, WAF and Turnstile at the edge.
